# OrHasharon

Site for Kehilat Or Hasharon: sermons (דרשות) and worship (הלל) from the community's YouTube channel.

Live: https://uriyastapps.github.io/OrHasharon/

- `index.html`, `style.css`, `app.js` – static site (GitHub Pages)
- `data/videos.json` – video catalog, generated by `scripts/fetch_videos.py`
- `.github/workflows/update-videos.yml` – refreshes the catalog every 6 hours

No backend; new YouTube uploads show up automatically.
